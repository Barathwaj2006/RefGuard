# Agent Registry

This registry tracks the participating agents in this shared workspace and their intended capabilities.

## Participating Agents (Examples)
The following agents may participate. Their roles are temporary and task-specific rather than permanent restrictions. Any agent can take on any role (frontend, backend, testing, integration, etc.) depending on the task assignment.

- Antigravity IDE / Antigravity 2.0
- Google Jules
- Google AI Studio
- Google Stitch
- GitHub Copilot
- Qwen

## Role Assignments
Role assignments are dynamic and managed per-task. Do not assume technology lock-in (e.g., assuming Jules is always backend). An agent must verify its current assignment before taking action.
